## What this does and does not show

- Web Analytics data starts on **15 September 2026**, and **16 September** is the day with the first large traffic
  (13 page views). This is the date visible in the chart.
- It does not establish an August start. The August dates come from the project record and the v0 chat history in
  [`PROJECT_ORIGIN.md`](PROJECT_ORIGIN.md): the Vercel project was created on 14 August 2026.
- Analytics only counts visitors after the analytics script was enabled, so the first data point is not the start of
  the project.
